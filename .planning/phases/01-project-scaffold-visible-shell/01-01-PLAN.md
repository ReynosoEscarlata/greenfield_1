<threat_model>
## Trust Boundaries

Phase 1 is a pure static client-side scaffold: no backend, no API, no auth, no user-supplied data processed, no persistence/localStorage, and no network calls beyond the local Vite dev server fetching local assets. There is effectively no untrusted-input trust boundary in scope.

| Boundary | Description |
|----------|-------------|
| developer machine → npm registry | `npm create vite` / `npm install` pull packages over the network (supply-chain surface) |
| (none — app runtime) | No client→server, no user→app data boundary exists; the page renders only hardcoded static placeholder text |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-SC | Tampering | npm install of scaffold dependencies | accept | All packages are official first-party Vite/React/TS/Oxlint tooling, verified against the npm registry and the official `vitejs/vite` GitHub template in RESEARCH.md's Package Legitimacy Audit (zero externally-selected packages). No `[ASSUMED]`/`[SUS]`/`[SLOP]` packages introduced — no install checkpoint required. |
| T-01-I | Information Disclosure | rendered page | accept | The shell renders only hardcoded static placeholder strings ("Turnero", "Cola", "Ventanillas", placeholder copy). No PII, no patient data, no secrets, no env vars are rendered or stored. PRIVACY-01 concerns arrive in Phase 7 with real ticket data. |
| T-01-S/R/D/E | Spoofing / Repudiation / DoS / Elevation | app runtime | accept | Not applicable — no auth, no sessions, no server, no privileged operations, no persistence exist in this static scaffold. Minimal attack surface by design. |

**Note (ASVS L1):** Phase 1's attack surface is intentionally minimal — a static placeholder shell with no network calls beyond the local dev server, no user-supplied data, and no persistence. No HIGH-severity threats apply; all dispositions are "accept" with documented rationale rather than invented mitigations.
