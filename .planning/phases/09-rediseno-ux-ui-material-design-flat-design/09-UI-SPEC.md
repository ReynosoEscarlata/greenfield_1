## Design System

| Property | Value |
|----------|-------|
| Tool | Tailwind CSS v4 via `@tailwindcss/vite` devDependency |
| Preset | not applicable — custom `@theme` block in index.css |
| Component library | none — no shadcn, no external component registry |
| Icon library | none — Unicode "×" for remove button (unchanged from prior phases) |
| Font | Roboto via Google Fonts CDN (`<link>` added to index.html) |
| Design language | Material Design 3 (Material You) — light mode only |
| Mode | Light mode only. No `@media (prefers-color-scheme: dark)`. (D-02) |

**No shadcn gate required:** project is not using shadcn. CLAUDE.md §What NOT to Use explicitly excludes component libraries.

**Tailwind v4 exception:** CLAUDE.md §What NOT to Use targets runtime dependencies. `@tailwindcss/vite` is a build-time devDependency and is the user-approved exception (CONTEXT.md §Stack constraints + D-23). It generates zero runtime JavaScript.

**Google Fonts CDN note:** Adding `<link href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;500;700&display=swap" rel="stylesheet">` to index.html causes one external network request at page load. This is acceptable for a single-machine clinic display. Use `display=swap` to avoid FOIT (D-18).

## Spacing Scale

Derived from the Tailwind class mapping table in CONTEXT.md §code_context. Tailwind v4 default unit: 1 spacing step = 0.25rem = 4px.

| Tailwind Step | Value | Tailwind Classes | Usage |
|--------------|-------|-----------------|-------|
| 1.5 | 6px | `mt-1.5` | Warning message top margin (`.ventanilla-warning`) |
| 2 | 8px | `top-2 right-2 mt-2 py-2` | Remove button position (top/right); call-next button top margin; chip vertical padding |
| 3 | 12px | `py-3` | Vertical padding for all three main action buttons |
| 4 | 16px | `p-4 px-4 gap-4` | Ventanilla card internal padding; chip horizontal padding; ventanilla grid gap |
| 6 | 24px | `p-6 px-6 mb-6` | Queue strip card padding; main button horizontal padding; queue strip bottom margin |
| 8 | 32px | `px-8 py-8 w-8 h-8` | Page container padding (horizontal and vertical); remove button size |

**Exceptions:**
- `mt-1.5` = 6px is not a multiple of 4. It is inherited from the current codebase warning spacing and is preserved as-is.
- Remove button uses `w-8 h-8` = 32px which is on scale.

**Phase 9 spacing philosophy:** All new MD3 button padding uses `px-6 py-3` (24px × 12px). Cards use `p-4` (16px). The page container keeps `px-8 py-8` (32px) from the existing `.page` class.

**Source:** CONTEXT.md §code_context class mapping table + existing src/index.css values.

**CRITICAL — ventanilla-ticket-flash preservation (D-26):**
The class `.ventanilla-ticket-flash` MUST remain as a named CSS class in `index.css`. It MUST NOT be migrated to a Tailwind utility or `@theme` variable. The Phase 6 tests (`App.test.tsx`, FEEDBACK-02 describe block) use DOM queries for this class name. Removing or renaming it breaks tests.

**CRITICAL — @keyframes update (D-08):**
The `@keyframes ticket-flash` animation color changes from amber `#fbbf24` to primary blue with opacity:
```css
@keyframes ticket-flash {
  from {
    background-color: rgba(25, 118, 210, 0.25);
  }
  to {
    background-color: transparent;
  }
}

.ventanilla-ticket-flash {
  animation: ticket-flash 600ms ease-out forwards;
  border-radius: 8px;  /* increased from 4px to suit 48px ticket display */
}
```

## Registry Safety

| Registry | Packages / Blocks Used | Safety Gate | Notes |
|----------|----------------------|-------------|-------|
| npm (official) | `tailwindcss@^4.x` (devDep), `@tailwindcss/vite@^4.x` (devDep) | build-tool devDependency — generates CSS at build time; zero runtime JS in the browser bundle | Official Tailwind Labs packages; no vetting gate required |
| Google Fonts CDN | `fonts.googleapis.com` (Roboto, weights 400/500/700) | External HTTP request at page load; no JS executed | Network dependency — clinic display requires internet access or local font fallback |
| shadcn | none | not applicable | |
| Third-party component registries | none | not applicable | |

**@tailwindcss/vite safety rationale:** This is a Vite plugin that processes CSS at build time (PostCSS pipeline). It produces no JavaScript in the output bundle. Its source is the official Tailwind Labs repository. No registry vetting gate is required for official npm packages from known maintainers.

**Google Fonts CDN note:** The `<link>` tag in `index.html` makes a request to `fonts.googleapis.com` at page load. If the clinic network is restricted or offline, Roboto will not load and the browser will fall back to `sans-serif` (system sans stack). This is acceptable — the app remains fully functional; only the font changes visually.

## Critical Invariants (must survive Phase 9)

1. **`.ventanilla-ticket-flash` class stays in CSS** — `App.test.tsx` FEEDBACK-02 tests query for this class. Do not rename, remove, or migrate to Tailwind utility (D-26).
