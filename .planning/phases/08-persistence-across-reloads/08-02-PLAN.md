## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Tampering | localStorage → loadFromStorage() | mitigate | try/catch around JSON.parse (D-01/D-03): any parse failure returns initialState; tampered data cannot produce an unhandled exception or corrupt React state beyond the session |
| T-08-02 | Information Disclosure | 'turnero-v1' localStorage key | accept | Stored data is ticket numbers (integers) and window numbers only — no PII, no credentials, no tokens. PRIVACY-01 guarantees no patient-identifying data ever enters state. Tampering affects only the tamper's own browser session. |
| T-08-03 | Denial of Service | localStorage quota | accept | QueueState JSON is under 1KB even with many tickets and windows. Storage quota exhaustion is theoretical at this scale; no guard needed. |
</threat_model>
